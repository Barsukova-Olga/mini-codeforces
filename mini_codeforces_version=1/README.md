# Mini Codeforces

Учебный веб‑проект на Spring Boot, имитирующий базовые элементы Codeforces: главную страницу, регистрацию/вход, список пользователей и публикацию объявлений (notices). Интерфейс реализован на FreeMarker, данные сохраняются через JPA в базе MariaDB.

## Возможности

- регистрация и вход пользователей;
- просмотр списка пользователей и карточки конкретного пользователя;
- публикация объявлений (notice) и вывод их в боковой панели;
- серверная валидация форм.

## Технологии

- Java 8
- Spring Boot
- MariaDB 
- Maven Wrapper

## Запуск

1. Установите Java 8 и убедитесь, что доступен `mvn` или используйте `./mvnw`.
2. Настройте параметры базы данных в `profile.properties` (URL, пользователь, пароль).
3. Запустите приложение. Приложение будет доступно по адресу `http://localhost:8080`.
